About the app

StarlitDesk Pin Publisher is a private tool for StarlitDesk, a small Etsy shop (etsy.com/shop/StarlitDesk) that sells spreadsheet tools for handmade sellers. It posts Pins of our own products to our own Pinterest boards and does nothing else. It is not a public app: only the StarlitDesk Pinterest account connects to it; no other users sign in.

How it works: the shop owner approves each Pin one by one from a pin sheet (image, title, description, alt text, link to our Etsy listing, board). A scheduled GitHub Actions workflow then creates the approved Pins through API v5, at most three per day, and skips Pins already posted. Every Pin carries alt text and the AI-modified label (AI_MODIFIED), because our product images are partly made with AI tools.

Access: OAuth 2.0 with scopes boards:read, boards:write, pins:read and pins:write, used only on our own boards and Pins. Tokens are kept as encrypted GitHub secrets. We store only the ID and posting time of each Pin we create. We do not collect, store or share data about other Pinterest users or any third party, and we never sell data.

StarlitDesk privacy policy

This policy explains what the StarlitDesk Pin Publisher accesses, what it keeps and why. It covers this tool only. Our Etsy shop is covered by Etsy's privacy policy, and Pinterest itself by Pinterest's privacy policy.

Who is responsible

StarlitDesk, an individual seller based in Sweden, operates the tool. You can reach us as described under Support.

What the tool accesses on Pinterest

We sign in to our own Pinterest account through Pinterest's official OAuth 2.0 flow and grant the tool these permissions:

  • boards:read to find the ID of our own board that a pin goes on.
  • boards:write because Pinterest lists it for the endpoint that creates pins. The tool does not create, edit or delete boards.
  • pins:write to create pins on our own boards.
  • pins:read to check that a pin we created was published.

The tool does not read other people's pins, boards, profiles, followers or messages. Before going live, we test it in Pinterest's sandbox, where test pins are visible only to our own account.

What the tool stores

  • Access tokens. The OAuth access and refresh tokens for our account, stored only as encrypted GitHub Actions secrets. When Pinterest issues a new refresh token, the tool replaces the old secret with it.
  • Our pin queue. The pins we wrote ourselves: image file, title, description, alt text, AI label, link to our listing, target board, earliest posting date and a record that the pin was approved.
  • A run log. Which queue items were posted, when, and the ID Pinterest gave each new pin, so that nothing is posted twice.

Apart from the ID of each pin we created, the tool does not keep copies of information it reads from Pinterest. When it needs a board ID or a pin's status, it asks the Pinterest API again.

Personal data

The tool does not collect or process personal data about other people. It handles no Etsy buyer data, and this page and the tool use no cookies, analytics or ad tracking. When someone clicks one of our pins, they go to our Etsy listing, where Etsy's and Pinterest's own privacy policies apply.

Sharing

We do not sell or share data from the tool. It relies on two services: GitHub, which hosts the code, runs the scheduled jobs and stores the encrypted tokens, and Pinterest, which receives the pins we publish.

Retention and deletion

Tokens are kept only while the tool is in use. If we stop using it, we delete the secrets and remove the app's access to our account in Pinterest's settings. The pin queue and run log are kept for as long as the tool is in use, then deleted.

Your rights

If you think the tool holds personal data about you, contact us and we will answer. People in the EU can also contact their data protection authority; in Sweden that is the Swedish Authority for Privacy Protection (imy.se).

Changes

If the tool starts to access or store anything new, we update this page and the date at the top before that change goes live.
