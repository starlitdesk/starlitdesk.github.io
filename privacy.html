StarlitDesk Pin Publisher

StarlitDesk Pin Publisher is a private tool that posts Pins of our own products to our own Pinterest boards and does nothing else. It is not a public app: only the StarlitDesk Pinterest account connects to it; no other users sign in.

How it works: the shop owner approves each Pin one by one from a pin sheet (image, title, description, alt text, link, board). A scheduled GitHub Actions workflow then creates the approved Pins through Pinterest API v5, at most three per day, and skips Pins already posted. Every Pin carries alt text and the AI-modified label, because our product images are partly made with AI tools.

What the tool accesses on Pinterest

We sign in to our own Pinterest account through Pinterest's official OAuth 2.0 flow and grant the tool these permissions:

  • boards:read to find the ID of our own board that a Pin goes on.
  • boards:write because Pinterest lists it for the endpoint that creates Pins. The tool does not create, edit or delete boards.
  • pins:write to create Pins on our own boards.
  • pins:read to check that a Pin we created was published.

The tool does not read other people's Pins, boards, profiles, followers or messages. Before going live, we test it in Pinterest's sandbox, where test Pins are visible only to our own account.

What the tool stores

  • Access tokens. The OAuth access and refresh tokens for our account, stored only as encrypted GitHub Actions secrets. When Pinterest issues a new refresh token, the tool replaces the old secret with it.
  • Our Pin queue. The Pins we wrote ourselves: image file, title, description, alt text, AI label, link, target board, earliest posting date and a record that the Pin was approved.
  • A run log. Which queue items were posted, when, and the ID Pinterest gave each new Pin, so that nothing is posted twice.

Apart from the ID of each Pin we created, the tool keeps no copies of information it reads from Pinterest. It handles no buyer data and no personal data about other people. When someone clicks one of our Pins, Pinterest's privacy policy applies, and then the policy of the site the Pin links to.

Sharing, retention and deletion

We do not sell or share data from the tool. It relies on two services: GitHub, which hosts the code, runs the scheduled jobs and stores the encrypted tokens, and Pinterest, which receives the Pins we publish. Tokens are kept only while the tool is in use. If we stop using it, we delete the secrets and remove the app's access in Pinterest's settings; the Pin queue and run log are then deleted too.

StarlitDesk Pin Publisher uses the Pinterest API. It is not made, endorsed or reviewed by Pinterest.
